# China PCA Face Research

中国人群人脸统计建模与跨时期变化研究。

A research project on statistical facial appearance modeling
and temporal analysis using Principal Component Analysis (PCA).

## 1. Research Objectives

本项目拟研究以下方向：

1. 当代中国男性与女性人群的统计平均脸。
2. 基于明确评价标准和样本筛选机制的高评价人群平均脸。
3. 不同历史时期人群面部统计特征的变化。
4. PCA 主成分、特征脸及重建效果分析。

## 2. Research Principles

- 以可追溯的数据来源和可靠的人群元数据为基础。
- 区分总体代表性样本与经过筛选的高评价样本。
- 不将主观审美评价描述为客观事实。
- 记录数据清洗、对齐、标准化和模型参数。
- 保证实验可重复，并保留研究过程记录。
- 尊重数据集许可、隐私和个人生物识别数据保护要求。

## 3. Repository Structure

- `data/`: Dataset metadata and local data organization.
- `src/`: Core algorithms and source code.
- `notebooks/`: Exploratory research.
- `scripts/`: Data processing scripts.
- `configs/`: Experiment configurations.
- `tests/`: Automated tests.
- `results/`: Experimental outputs.
- `docs/`: Research documentation.

## 4. Data Policy

原始人脸图片、未经授权的数据集、个人生物识别信息和
大型模型文件不应上传至本公开仓库。

数据集的来源、版本、许可和允许用途应记录在
`data/metadata/` 中。
