# Project Scope and Research Questions

## 1. Main Objective

利用 PCA 建立人脸统计模型，研究人群平均面部特征、
不同评价样本的差异以及跨时期变化。

## 2. Research Tracks

### Track A: Contemporary Population Mean Faces

分别研究有可靠元数据支持的男性和女性样本。

重点：
- 样本代表性
- 人脸检测与关键点对齐
- 图像标准化
- 平均脸
- PCA 特征脸
- 方差解释率与重建误差

### Track B: High-Rated Appearance

建立独立的高评价样本子集。

必须明确：
- 评价者构成
- 评价标准
- 评分或筛选方法
- 样本数量
- 评价偏差与局限性

不得将未经验证的审美判断称为公认结论。

### Track C: Temporal Analysis

比较不同历史时期的数据。

需要评估：
- 数据采集年代
- 样本年龄和人口构成
- 图像质量与拍摄条件
- 数据来源变化
- 不同时期样本的可比性

## 3. Methodology

1. Dataset discovery and licensing review.
2. Dataset inventory and metadata validation.
3. Face detection and landmark alignment.
4. Image normalization and quality control.
5. Mean-face computation.
6. PCA and eigenface analysis.
7. Reconstruction and robustness evaluation.
8. Temporal and subgroup comparison.

## 4. Open Questions

- Which datasets are suitable and legally reusable?
- How should population representativeness be evaluated?
- What rating protocol defines the high-rated subset?
- Which historical periods have comparable data?
- Which alignment and normalization methods are appropriate?
